# Employee Data Analytics Using Apache Spark SQL

## Project Overview
This project analyzes employee data using Apache Spark SQL to discover insights about salaries, departments, employee experience, performance ratings, and bonuses.

## Objectives
- Explore employee data using Spark SQL.
- Identify missing values and improve data quality.
- Analyze salary distributions across departments and job titles.
- Study the relationship between experience and salary.
- Analyze employee performance ratings and bonuses.
- Practice SQL queries, aggregations, joins, and window functions.

## Dataset
The dataset contains 250 fictional employee records with information such as department, job title, location, hire date, salary, years of experience, performance rating, and bonus percentage.

**Note:** The dataset contains fictional data for educational purposes.
